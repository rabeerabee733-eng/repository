# مستودع العاصمة

Independent Arabic medicine catalog with search, product reference photos, and a WhatsApp inquiry cart.

- Static public directory: `dist`
- Validation: `node verify.mjs && node cart.test.mjs`
- WhatsApp: +963967765704
- No OpenAI service, account, API key, database, or external font requests are required.
- Displayed prices come from the supplied list and require supplier confirmation.
- Publish this branch as a separate Render static site; unrelated branches are not used.
